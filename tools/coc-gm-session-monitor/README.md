# CoC GMセッションモニター v0.11（限定テスト版）

CoC 6版・7版（混在卓を含む）のGM/KP向け補助ツール。探索者を一度読み込めば、MP・SANの管理、能力値・技能の比較、choice、ダイス表、卓報告、卓後ログの受け渡しを1ページで扱う。

- 限定テスト版：`noindex`、ポータル（`assets/data/tools.json`）には載せない。解析タグ（analytics.js）も読み込まない。
- 設計：プロジェクトの `gm-session-monitor/blueprint-v0.2-review-and-v1-plan.md`（ブループリント v0.1 の改訂メモ）。v1はGM補助ページのみ。コマ作成・職業検索・成長/統計の内蔵・呪文/神話生物/色はv2以降。

## できること

| パネル | 内容 |
|---|---|
| 卓 | 作成・切替・複製・アーカイブ（読み取りのみ）/復元・削除。JSONバックアップ/復元（復元前に件数を確認） |
| 読込 | こま形式JSON（いあきゃら / キャラッシュ / Charaeno、連結可）とキャラクター保管所テキストを `shared/coc-palette` の `buildCharacter` で取込。版の自動判定＋手動変更。同じキャラシURLは「更新（現在値保持）」か「別キャラ」を選べる。手入力も可 |
| カード | HP/MP/SAN/幸運（表示項目で選択）の±1・直接入力。最大値・0未満は止める。基準SAN、不定の狂気ライン `ceil(基準/5)`、1回5以上の減少を警告（確定はしない）。並べ替え・非表示・色・PL・HO |
| 時間経過 | ゲーム内時間を進め、MPを回復（6版 POW/24・7版 1 per 時、端数持越し、満タンで端数破棄）。基準SANの付け替えも選択。1操作として取り消せる |
| 変動ログ | 前→後・理由・実時刻・ゲーム内時刻。直前の操作（一括含む）を取り消し（Ctrl/⌘+Z） |
| 比較 | 能力値（7版は ÷5 を併記、★は6版相当で比較、小数は丸めない）、技能（同名は同じ行、博物学↔自然などの名称差は注記つきで同じ行、版固有・分割技能は「—」、初期値補完は灰色、検索・カテゴリ・類似技能・強調・行の固定、数値クリックで `CCB<=` / `CC<=` をコピー） |
| チェック | 見出し・選択式（`質問 | A | B`）・一括追加、卓全体/探索者ごと、未完了のみ |
| choice | 対象選択、選ぶ数、シークレット、コメント、名前形式。`, [ ]` や改行を含む名前はコピー不可 |
| ダイス表 | 複数表、重複＝重み、BCDiceオリジナル表形式のテキスト、choice形式、JSON入出力 |
| 卓報告 | PC一覧から短文を生成。卓報告ジェネレーターへ既存の pendingImport 方式で渡す（HO・SAN・メモは渡さない） |
| 卓後ログ | 貼付/ファイルを、既存の `trpg-web-tools:session-log-transfer` 方式で成長チェッカー・ダイス解析アナライザーへ渡す（このツールには保存しない） |

## 未検証（実機で確認するまで注意書きを出している）

- `choice2[...]`（選ぶ数2以上）と `S` 接頭辞のシークレットがココフォリアで動くか
- ダイス表テキストをココフォリアの `/roll-table` で読めるか

## 保存

`localStorage["coc-gm-session-monitor:v1"]` に1キー（`schemaVersion`、`revision`）。キャラクター（原本テキスト・シート値）は全卓共通、HP/SAN等の現在値は卓ごと。他タブでの更新を検知したら保存を止めて再読込を促す。

## テスト

```sh
node --test tools/coc-gm-session-monitor/tests/core.test.mjs
node tools/chat-palette-formatter/tests/run.mjs   # 共通パーサーの回帰
```

`shared/coc-palette/parser.js` には参照用に `categorize` / `initialValueCandidates` / `INITIAL_6E` / `INITIAL_7E` を公開する追記だけをしている（既存の挙動は変えない）。
