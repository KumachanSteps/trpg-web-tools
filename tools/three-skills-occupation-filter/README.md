# 三大探索技能｜職業の選択肢 v0.1

三大探索技能を固定の職業技能に含む職業をチェックボックスで検索し、条件を増やすことで職業の選択肢がどう変わるか比較する静的ツールです。チェックはAND条件。未選択は170件すべてを表示します。

選択技能や興味Pでの取得可能性とは別の集計です。「該当しない職業では技能を取得できない」「この職業は不適切」といった判定ではありません。採用・解釈は使用するルールと卓の合意を優先してください。

## データ

ユーザー提供の `three-skills-codex-handover.zip` 内 `occupation-skills-170.json` をそのまま収録。元データ表記は「探索者ヘルパー v2.47」。ルールブック原本との照合は未実施です。2015が73件、2026が70件、プレイングガイドが27件。パルプクトゥルフは含みません。出典＋IDで別職業として数えます。

完全一致の `skills` だけで判定。全技能と選択肢はJSON内に保持していますが、一覧には職業名・出典・選択した技能だけを表示します。固定フラグとの一致・170件・出典・IDを読み込み時に検証します。

出典フィルターの分母は選択した出典の件数です。全出典の一致数も併記します。版を混ぜた分母であることを明示し、ポイント計算機とは独立しています。

## 起動と検証

リポジトリルートで `python3 -m http.server 8124 --bind 127.0.0.1` を起動し、`/tools/three-skills-occupation-filter/` を開きます。JSON読込のためHTTPサーバーを使用してください。ビルド・外部パッケージ不要。

```sh
node --test tools/three-skills-occupation-filter/tests/counts.test.mjs
```

全8通り×4出典範囲の集計、分母・全出典数、選択技能を含めないこと、不正データの検出を検証します。元のポイント計算機の計算ロジックは変更しません。
