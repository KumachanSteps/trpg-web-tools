カットイン作成スタジオ v0.10 / 2026.11.28

立ち絵を入れて型を選ぶだけで、ココフォリアのカットインで使える動く画像（APNG / WebP）を作れます。

使い方

  1. 1. 右下の「立ち絵」で画像（PNG・WebP・JPG）を選びます。白い背景の画像は、背景を自動で消して透過にします。
  2. 2. 顔の位置は自動で合わせます。ずれているときは「顔の位置」の小さな画面で丸をドラッグして直します。
  3. 3. 左の「型」からカットインの型を選び、「調整」で文字・色・書体・速さを変えます。変えた内容は型ごとにこのブラウザに保存されます。
  4. 4. プレビューの立ち絵はドラッグで動かせます。マウスホイール（スマホは2本指）で拡大・縮小します。
  5. 5. 「書き出し」で APNG（または WebP）を書き出し、ココフォリアのカットインに登録します。容量は3MB前後を目安にしてください（5MBを超えるとダウンロードできません）。

※ 立ち絵はこのブラウザの中（IndexedDB）にだけ保存され、サーバーには送信されません。

※ ココフォリアのカットインでは「1回再生」の画像が流れないことがあるため、書き出しの初期値は「ずっとループ」です。カットインに効果音をつけると、音が鳴り終わったところでカットインが消えます。

※ 限定テスト版です。型や機能は順次追加していきます。

利用ルール

本メーカーで生成したAPNG画像は、TRPGセッション・配信・動画・ゲームなどの素材として使用できます。使用にあたっての申請・報告は不要です。

許可

  • 商用・非商用、個人・法人を問わず、TRPGセッション・配信・動画・ゲーム・Webサイト等の制作物での使用
  • 生成したAPNG素材の加工（速度、色彩、大きさ、合成等）
  • TRPGシナリオ本文、ココフォリアルームデータ、配布ZIP等への収録

禁止

  • 加工・改変の有無を問わず、生成物そのものを素材として二次配布・販売・転売・譲渡する行為
  • 生成物を素材として不特定多数へ公開する行為（素材集・素材パック・テンプレート集への収録を含む）
  • 生成物の自作発言、および本ツールそのもの・主要部分の無断複製、再配布、転載

※作品の一部としての同梱、およびセッションに必要な範囲での参加者間の共有は可能です。APNG素材そのものの提供を主目的とした配布はできません。
