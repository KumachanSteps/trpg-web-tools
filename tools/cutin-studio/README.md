# カットイン作成スタジオ（Cut-in Studio）

ココフォリア用のカットイン（立ち絵 ＋ 文字 ＋ フラッシュなどの演出）を、型を選んで調整し、APNG / WebP で書き出すツール。
v0.10 は限定テスト版（`noindex`、ポータルのカードなし、直リンクのみ）。

## 画面

| パネル | 役割 |
| --- | --- |
| 型（左） | 7つの型（斜めスラッシュ／横ながし／まなざし／キャラ紹介／スタイリッシュ／対決／たてながし）。カードにマウスを乗せると動く |
| 調整（左） | 名前・小見出し・ひとことなどの文字、書体（ゴシック／明朝／丸ゴシック／筆文字／太字／PCのフォント）、イメージカラー、速さ、フラッシュ、退場の有無。型ごとにこのブラウザへ保存 |
| プレビュー（右） | 960×540 の舞台。立ち絵はドラッグで移動、ホイール／ピンチで拡大縮小 |
| 立ち絵 | PNG / WebP を読み込む。白い背景は自動で消す（切り替え可）。顔の位置と大きさを推定し、顔の枠で直せる。IndexedDB に保存し、送信しない |
| 書き出し | APNG（既定・ループ）と WebP。容量の目安：3MB 未満が基本、3〜5MB は注意、5MB を超えるとダウンロードできない（「軽くする」で 色数 → FPS → 大きさ の順に下げる） |

ココフォリアでは1回だけ再生する画像はカットインとしてうまく出ないことがあるため、既定はループ。

## ファイル

```
index.html
css/cutin-studio.css     演出APNGメーカーの CSS ＋ このツールの追加分
js/templates.js          描画（時刻 t → 1コマ。同じ t なら同じ絵）と7つの型
js/portrait.js           立ち絵の読み込み、白背景の除去、顔の推定、IndexedDB
js/main.js               画面、プレビュー、書き出し
js/apng-encoder.js       文字画像APNGメーカーと同じエンコーダ
js/webp-encoder.js       同上
```

型を足すときは `templates.js` の `TEMPLATES` に1件足し、描画関数を書く。名前と説明は `main.js` の `NAMES` / `DESCS`。
