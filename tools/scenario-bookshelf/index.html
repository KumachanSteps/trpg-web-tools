持っているシナリオの本棚。フォルダを登録すると自動で並び、フォルダ名もルールに沿って一括で整えられます。

v0.1.0 2026.10.24

フォルダを登録：シナリオを保存しているフォルダを選ぶと、その中のフォルダ名・ファイル名（PDF・ZIP）をシナリオライブラリと照合して本棚に並べます。読むのは名前だけで、ファイルの中身は読み込まず、どこにも送信しません。

照合：候補が複数ある作品は「照合待ち」になります。表の候補から選ぶと次回のスキャンでも覚えています。ライブラリに無い作品は「未登録」です。

フォルダ名を整理：命名ルールを決めると、照合できたフォルダの新しい名前を確認できます。名前の変更は書き出したスクリプトを本棚フォルダで実行して行います（元に戻すスクリプトも出せます）。

保存先：本棚はこのブラウザ内（IndexedDB）に保存されます。別の端末へは JSON 出力 → 読み込みで移せます。
