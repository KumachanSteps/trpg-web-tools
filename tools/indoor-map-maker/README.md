# TRPG室内図メーカー

TRPGの探索シーンで使う室内の見取り図を、ブラウザだけで作成するツールです。1マス = 0.5m のグリッドに部屋を置くと、壁が自動でつきます（隣り合う部屋の間は内壁、外に面する辺は外壁、バルコニーは手すり）。

- **テンプレート**：19種を5つの分類で選べます。実際の間取りの定石（北側の玄関と中央の水回り、中廊下型の客室・病棟、片廊下型の校舎、上下階でそろえた階段とEVなど）に沿って手作りしています。「家具なし（間取りだけ）」でも読み込めます。「隠し手がかり入りで読み込む」をオンにすると、どのテンプレートにも手がかり（日記・写真・鍵・メモ・刃物など、説明つき）を置いた版になります。
  - 住宅：1LDKアパート・2LDKマンション・一戸建て（2階建て）・洋館（地下1階〜2階）・アパート（1K×8戸・外廊下）・タワーマンション（1F共用部・内廊下の基準階）
  - 宿泊・医療：ホテル（1Fロビー・2F宴会場とチャペル・3Fジムと屋内プール・7F客室・8Fスイートとスカイラウンジ）・病院（外来・病棟）
  - 公共・学校：学校（校舎2階建て）・警察署（取調室と留置場）・図書館（B1閉架書庫とGM用の禁書庫）・大学（講義棟・研究棟）
  - 娯楽施設：バー（地下1階）・ライブハウス（地下1階）・劇場／コンサートホール
  - 廃墟・事件：廃病院・廃屋・廃ビル・事件現場
- **部屋**：種類（リビング・寝室・和室・水回り・廊下・医療・儀式・屋外など）ごとに色と床の模様がつきます。PL向けの別名、GMメモ、GM専用（PLには見せない）、壁を作らない（LDKのゆるい区切り）を設定できます。
- **隠し手がかり**：家具・文字を「隠し手がかり」にすると虫めがねの印がつき、キャンバス右上の「隠し手がかり ON/OFF」（Cキー）で表示を切り替えられます。GM/PL表示とは別なので、PLに部屋の中は見せつつ、まだ見つかっていない手がかりだけ伏せておけます。書き出しでも「表示する / 隠す」を選べます。
- **ドア・窓**：片開き・両開き・引き戸・引違い戸・折れ戸・自動ドア・シャッター・開口・施錠・隠し扉（GMのみ）・壊れたドア・壁の穴、窓・掃き出し窓・鉄格子・板でふさいだ窓・割れた窓。壁に近づけると吸い付き、ドアはカーソルのある側に開きます。
- **壁ツール**：部屋の外周以外に、間仕切り・ガラス壁・手すり・柵・鉄格子・崩れた壁を引けます。
- **家具・小物**：約120種（階段・エレベーター、リビング、寝室、キッチン、水回り、オフィス、病院・研究、学校・図書館、娯楽・スポーツ、探索・ホラー、屋外）。壁の近くでは背中を壁に向けてぴったり付きます。
- **表示スタイル**：カラー / モノクロ図面 / ブループリント / 古びた図面 / ホラー調査。マップ設定の「部屋名を表示」をオフにすると、部屋の中の名前を消した図にできます（書き出しにも反映）。
- **書き出し**：PNG（この階だけ / すべての階を並べる / 階ごとに別の画像）。すべての階を並べると横に長くなりすぎるとき（細長い校舎や5フロアのホテルなど）は折り返して並べます。大きすぎる画像はブラウザが扱える大きさ（1辺16000px・総画素数4000万px、iPhone / iPad は約1677万px）まで自動で縮小します。PL用はGM専用のものと隠し扉を除きます。1マスのピクセル数を選べるので、ココフォリアなどのマップ画像にそのまま使えます。
- **保存**：作業はブラウザに自動保存。`.trpgmap.json` でファイルに保存・読み込みできます。

画面表示は日本語・英語・韓国語に対応しています。

## ファイル構成

```text
tools/indoor-map-maker/
├─ index.html
├─ css/indoor-map-maker.css   観測所の共通デザイン（文字画像APNGメーカーと同じ色・ヘッダー）＋エディターの部品
└─ js/
   ├─ model.js      データの形、部屋の種類・ドア/窓・壁の種類、壁の自動生成（computeWalls）、寸法の表示
   ├─ assets.js     家具・小物の描画（1つずつ線画で描く。外部画像なし）
   ├─ render.js     表示スタイル、床の模様、壁・ドア・窓・家具・ラベルの描画、PNGの書き出し
   ├─ templates.js  テンプレート19種（マス単位の手作り）
   ├─ i18n.js       画面文言（日本語 / English / 한국어）
   └─ editor.js     エディター本体（ツール、吸着、プロパティ、階、履歴、保存、書き出し）
```

## 仕組みのメモ

- 座標の単位はマス（1マス = 0.5m）。部屋は整数マス、家具・ドア・窓は0.25マス刻み。
- 壁はデータとして持たず、部屋の矩形から毎回計算します。各マスの持ち主（後に置いた部屋が上）を決め、辺ごとに「両側の部屋」から壁の種類を決めて、同じ種類の辺をつないで線にします。部屋の中に部屋を置く（ホテルの客室の浴室など）こともできます。
- ドア・窓は壁の線を切り取って描きます。隠し扉はPL表示では壁を切らないので、ただの壁に見えます。
- 家具は外形 `{x, y, w, h}` と向き `rot`（0/90/180/270）で持ちます。描画では「背中（壁側）が上」になるように描いてから回すので、壁際に置いたときに向きをそろえやすくしています。家具は壁より先に描くので、壁の線に合わせて置くと壁にぴったり付いて見えます。
- 部屋を動かすと、中の家具・ドア/窓・文字・入れ子の部屋も一緒に動きます（Altキーで部屋だけ）。
- 部屋の回転（R）は、中の家具・ドア/窓・文字・壁・入れ子の部屋ごと時計回りに90°回します。回したあとも部屋がマス目に乗るように、左上を整数マスにそろえます。
- PL表示（`visibleFloor(floor, true)`）では、GM専用の部屋を `masked` にして壁の枠だけ残し、中を灰色で伏せます。中の家具・文字・壁・入れ子の部屋・内側のドアは除き、部屋の縁のドア・窓は残します。選んだときのミニバーの目のボタンでGM専用を切り替えます。
- GM表示のときは作業スペースの左上に半透明の「GM用」（英語 GM view / 韓国語 GM용）を出し、GM用の書き出し画像にも上の帯に同じ文字を入れて、PL用と取り違えないようにしています。
- 隠し手がかりは家具・文字の `clue: true` で持ちます。`visibleFloor(floor, playerView, hideClues)` の3つめが true のとき除きます（GM専用の判定とは別）。ON/OFF はこのブラウザの設定として覚え、書き出しを開くとその時の状態が初期値になります。テンプレートの手がかりは `CLUES` に「階・部屋名・小物・説明」で書き、読み込むときに部屋の中の空いている場所（家具・ドアの開く範囲・部屋名を避けた、中央寄りの場所）を探して置きます。説明が1行で入らなければ2行・小さめの文字の順に試します。
- 部屋のロック（L）は `locked: true` で持ちます。ロック中の部屋は移動・大きさの変更・回転・削除ができず、クリックすると選ぶだけで、ドラッグは範囲選択になります。中の家具やドアは今までどおり編集できます。複製・貼り付けした部屋はロックが外れます。

## テンプレートの追加

`js/templates.js` の `makeFloor()` で階を組み立て、`TEMPLATES` に登録します。同じ間取りを並べたり回したりするときは `placer()` を使います（ローカル座標で書いた住戸を左右・上下反転や90°回転して置けます。アパートの鏡写しの住戸や、タワーマンションの風車形の配置で使用）。部屋名などの文字は `T(日本語, 英語, 韓国語)` で3言語を用意します。部屋同士は重ならないように（入れ子にする場合は完全に内側に）置き、ドアの開く範囲に家具を置かない、すべての部屋に玄関か階段から行ける、を目安にしています。
