# TRPG室内図メーカー

TRPGの探索シーンで使う室内の見取り図を、ブラウザだけで作成するツールです。1マス = 0.5m のグリッドに部屋を置くと、壁が自動でつきます（隣り合う部屋の間は内壁、外に面する辺は外壁、バルコニーは手すり）。

- **テンプレート**：33種を10の分類で選べます。実際の間取りの定石（北側の玄関と中央の水回り、中廊下型の客室・病棟、片廊下型の校舎、上下階でそろえた階段とEVなど）に沿って手作りしています。「家具なし（間取りだけ）」でも読み込めます。「隠し手がかり入りで読み込む」をオンにすると、どのテンプレートにも手がかり（日記・写真・鍵・メモ・刃物など、説明つき）を置いた版になります。
  - 住宅：1LDKアパート・2LDKマンション・一戸建て（2階建て・庭とウッドデッキ・駐車場の屋外）・洋館（地下1階〜2階・車寄せと噴水・薔薇園・温室・一族の墓所の屋外）・地下室のある洋風住宅（防音室・窓のない部屋・GM用の隠し部屋）・アパート（1K×8戸・外廊下）・タワーマンション（1F共用部・内廊下の基準階）
  - 宿泊・医療：ホテル（1Fロビー・2F宴会場とチャペル・3Fジムと屋内プール・7F客室・8Fスイートとスカイラウンジ）・病院（外来・病棟）
  - 公共・学校：学校（校舎2階建て）・警察署（取調室と留置場）・図書館（B1閉架書庫とGM用の禁書庫）・大学（講義棟・研究棟）
  - 娯楽施設：バー（地下1階）・ライブハウス（地下1階）・劇場／コンサートホール
  - 廃墟・事件：廃病院・廃屋・廃ビル・事件現場
  - 1920年代：もぐり酒場（理髪店の奥・合言葉の扉）・探偵事務所のある雑居ビル（1Fダイナーと質屋・2F事務所と住まい）
  - SF：調査船（機関室・ブリッジ・冷凍睡眠室・エアロック）・月面研究基地（中央ハブと4つのモジュール、GM用の封鎖ラボ）
  - 村・和風：古民家（土間とかまど・囲炉裏・田の字型の座敷・縁側、蔵・納屋・井戸・畑、GM用の座敷牢）・山あいの神社（鳥居と参道・拝殿・本殿・社務所、GM用の禁足地）・忍者屋敷（広縁と庭・どんでん返し・隠し階段で屋根裏・落とし穴・井戸への抜け道）
  - 自然・野外：洞窟（地底湖・祭壇の間・獣の巣・縦穴）・川沿いのキャンプ場（テントサイト・バンガロー・炊事場・管理棟、GM用の防空壕）
  - ファンタジー：冒険者の宿（酒場・厩舎・2Fの客室）・城（堀と跳ね橋・玉座の間・兵舎・地下牢）・地下迷宮（罠の回廊・宝物庫・主の間・隠し扉）・魔法使いの塔（螺旋階段・書庫・実験室・天文台、GM用の封印の間）
  - 屋外の階（「屋外」）は敷地図です。建物は屋根（斜線）として描き、玄関・勝手口・窓は屋内の階と同じ位置にあります。
- **部屋**：種類（リビング・寝室・和室・水回り・廊下・医療・儀式・屋外・土間・縁側／広縁・防音室・石造り（城・迷宮）・建物（屋根）・艦内（SF）・田畑・水辺・洞窟など）ごとに色と床の模様がつきます。洞窟は外周が岩壁になり、屋外どうし（庭・水辺・洞窟など）は壁なしでつながります。PL向けの別名、GMメモ、GM専用（PLには見せない）、壁を作らない（LDKのゆるい区切り）、部屋の壁の種類（ガラスの温室、厚い石壁、防音壁など）を設定できます。
- **隠し手がかり**：家具・文字を「隠し手がかり」にすると虫めがねの印がつき、キャンバス右上の「隠し手がかり ON/OFF」（Cキー）で表示を切り替えられます。GM/PL表示とは別なので、PLに部屋の中は見せつつ、まだ見つかっていない手がかりだけ伏せておけます。書き出しでも「表示する / 隠す」を選べます。
- **ドア・窓**：片開き・両開き・引き戸・引違い戸・折れ戸・自動ドア・シャッター・開口・施錠・隠し扉（GMのみ）・壊れたドア・壁の穴、窓・掃き出し窓・鉄格子・板でふさいだ窓・割れた窓。壁に近づけると吸い付き、ドアはカーソルのある側に開きます。壁に沿ってドラッグすると長さを決めて置けるので、「開口」や「壁の穴」で壁の好きな部分を消せます。
- **壁ツール**：部屋の外周以外に、間仕切り・ガラス壁・手すり・柵・鉄格子・崩れた壁・岩壁・石壁・防音壁を引けます。
- **家具・小物**：約165種（階段・地下への階段・床の扉・はしご・エレベーター、リビング、寝室、キッチン、水回り、オフィス、病院・研究、学校・図書館、娯楽・スポーツ、探索・ホラー、屋外、1920年代・和風、SF、自然・キャンプ、ファンタジー）。どこにでも置け、Altで吸着なしの自由配置もできます。壁の近くでは背中を壁に向けてぴったり付きます。
- **表示スタイル**：カラー / モノクロ図面 / ブループリント / 古びた図面 / ホラー調査。マップ設定の「部屋名を表示」をオフにすると、部屋の中の名前を消した図にできます（書き出しにも反映）。
- **書き出し**：PNG（この階だけ / すべての階を並べる / 階ごとに別の画像）。すべての階を並べると横に長くなりすぎるとき（細長い校舎や5フロアのホテルなど）は折り返して並べます。大きすぎる画像はブラウザが扱える大きさ（1辺16000px・総画素数4000万px、iPhone / iPad は約1677万px）まで自動で縮小します。PL用はGM専用のものと隠し扉を除きます。1マスのピクセル数を選べるので、ココフォリアなどのマップ画像にそのまま使えます。
- **保存**：作業はブラウザに自動保存。`.trpgmap.json` でファイルに保存・読み込みできます。

画面表示は日本語・英語・韓国語に対応しています。

## 仕組みのメモ

- 座標の単位はマス（1マス = 0.5m）。部屋は整数マス、家具・ドア・窓は0.25マス刻み。
- 壁はデータとして持たず、部屋の矩形から毎回計算します。各マスの持ち主（後に置いた部屋が上）を決め、辺ごとに「両側の部屋」から壁の種類を決めて、同じ種類の辺をつないで線にします。部屋の中に部屋を置く（ホテルの客室の浴室など）こともできます。
- ドア・窓は壁の線を切り取って描きます。隠し扉はPL表示では壁を切らないので、ただの壁に見えます。
- 家具は外形 `{x, y, w, h}` と向き `rot`（0/90/180/270）で持ちます。描画では「背中（壁側）が上」になるように描いてから回すので、壁際に置いたときに向きをそろえやすくしています。家具は壁より先に描くので、壁の線に合わせて置くと壁にぴったり付いて見えます。
- 部屋を動かすと、中の家具・ドア/窓・文字・入れ子の部屋も一緒に動きます（Altキーで部屋だけ）。
- 部屋の回転（R）は、中の家具・ドア/窓・文字・壁・入れ子の部屋ごと時計回りに90°回します。回したあとも部屋がマス目に乗るように、左上を整数マスにそろえます。
- PL表示（`visibleFloor(floor, true)`）では、GM専用の部屋を `masked` にして壁の枠だけ残し、中を灰色で伏せます。中の家具・文字・壁・入れ子の部屋・内側のドアは除き、部屋の縁のドア・窓は残します。選んだときのミニバーの目のボタンでGM専用を切り替えます。
- GM表示のときは作業スペースの左上に半透明の「GM用」（英語 GM view / 韓国語 GM용）を出し、GM用の書き出し画像にも上の帯に同じ文字を入れて、PL用と取り違えないようにしています。
- 隠し手がかりは家具・文字の `clue: true` で持ちます。`visibleFloor(floor, playerView, hideClues)` の3つめが true のとき除きます（GM専用の判定とは別）。ON/OFF はこのブラウザの設定として覚え、書き出しを開くとその時の状態が初期値になります。テンプレートの手がかりは `CLUES` に「階・部屋名・小物・説明」で書き、読み込むときに部屋の中の空いている場所（家具・ドアの開く範囲・部屋名を避けた、中央寄りの場所）を探して置きます。説明が1行で入らなければ2行・小さめの文字の順に試します。
- 部屋のロック（L）は `locked: true` で持ちます。ロック中の部屋は移動・大きさの変更・回転・削除ができず、クリックすると選ぶだけで、ドラッグは範囲選択になります。中の家具やドアは今までどおり編集できます。複製・貼り付けした部屋はロックが外れます。

## テンプレートの追加

`js/templates.js` の `makeFloor()` で階を組み立て、`TEMPLATES` に登録します。同じ間取りを並べたり回したりするときは `placer()` を使います（ローカル座標で書いた住戸を左右・上下反転や90°回転して置けます。アパートの鏡写しの住戸や、タワーマンションの風車形の配置で使用）。部屋名などの文字は `T(日本語, 英語, 韓国語)` で3言語を用意します。部屋同士は重ならないように（入れ子にする場合は完全に内側に）置き、ドアの開く範囲やドアの前に家具を置かない、すべての部屋に玄関か階段から行ける、浴室・トイレ・収納を通り抜けないと入れない部屋を作らない、階段とEVは上下階でそろえる、を目安にしています。屋外の敷地（庭・境内・キャンプ場など）は `fillYard()` で建物のない所を重ならない長方形に分けて埋めます。屋外の階（敷地図）では建物を `roof` の部屋として置き、ドア・窓は屋内の階と同じ座標にします。部屋に `wall: 'stone'`（城・迷宮）や `wall: 'glass'`（温室）、`wall: 'sound'`（防音室）を付けると、その部屋の周りの壁の種類が変わります（両側にあれば厚いほう）。
