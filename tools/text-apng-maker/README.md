# 文字画像APNGメーカー

TRPG用の文字アニメーション素材（背景透過APNG）をブラウザだけで作成するツールです。

- **メッセージ**：「戦闘開始」など画面中央のカットイン（テンプレートは「戦闘」「探索・事件」「GM」「シーン・時間」「判定」に分類。「判定」はCoC6・CoC7・エモクロア・ダブクロのシステム別）
- **トレイラー**：長めの文章を文頭から表示（1文字ずつ・1行ずつ・流れるように・スクロール、空行でページ送り）
- **場所・時間**：探索箇所・シーン・時刻のテロップ（上下から合流・浮かび上がる・字間が縮まる など）

登場のあとに退場させるかどうかは、プレビュー下の「退場あり」スイッチで切り替えます（オフにすると、文字を表示したまま終わる素材になります）。

書き出し形式は APNG / PNG静止画 / 連番PNG（ZIP）。画面表示は日本語・英語に対応しています。

## ファイル構成

```text
tools/text-apng-maker/
├─ index.html
├─ css/text-apng-maker.css
└─ js/
   ├─ engine.js        レイアウト（横書き・縦書き・禁則・自動縮小）、タイムライン、エフェクト、描画
   ├─ apng-encoder.js  APNG / ZIP エンコーダー（外部ライブラリなし）
   ├─ fonts.js         Google Fonts の遅延読み込み、フォントファイル・PCフォントの利用
   ├─ presets.js       モード別の初期値・テンプレート・スタイル/グラデーション/サイズのプリセット
   ├─ controls.js      設定パネル（宣言的なスキーマからUIを生成）と効果カードのミニプレビュー
   ├─ icons.js         テンプレートのアイコン（線画のSVG）
   ├─ i18n.js          画面文言（日本語 / English）
   ├─ main.js          状態管理・保存、プレビュー再生、書き出し処理
   └─ shortcut.js      キーボードショートカット
```

## 仕組みのメモ

- 描画は決定的（乱数は時刻と文字番号から生成）なので、プレビューと書き出しの見た目が一致します。
- 文字ごとに「光彩」「影＋外側の縁取り」「縁取り＋塗り」の3層のスプライトを事前に作り、フェード中に下の層が透けないよう本体の形でくり抜いています。
- ぼかしは文字スプライト単位の小さなキャンバスでかけています（全面レイヤーに `ctx.filter` をかけるより大幅に高速）。
- APNGはブラウザ標準の `CompressionStream('deflate')` で圧縮し、前フレームとの差分矩形だけを保存します（dispose: NONE / blend: SOURCE）。同じ絵が続くフレームは1枚にまとめて表示時間を延ばします。
- 256色モードは1回目の走査で変化した領域の色だけを集計し（メディアンカット＋k-means）、2回目の走査で変化した矩形だけをパレット番号に変換します。255色以内に収まる場合は劣化なしのパレットになります。
- 「APNG非対応の環境では完成状態の静止画を表示」をオンにすると、アニメーションとは別のデフォルト画像（IDAT）として完成状態を埋め込みます。

## 動作要件

- `CompressionStream` に対応したブラウザ（Chrome / Edge 80+、Firefox 113+、Safari 16.4+）。
- Google Fonts を使うにはネットワーク接続が必要です（読み込めない場合は代替フォントで描画します）。

## テンプレートの追加

`js/presets.js` の `TEMPLATES` に、モードごとの配列として追加します。`patch` には初期値（`BASE`）からの差分だけを書きます。文章は `text` / `subText` に日本語・英語の両方を用意します。メッセージのテンプレートには、分類（`TEMPLATE_GROUPS` のID）を `group` に指定します。分類に `systems` がある場合は、システムのIDを `system` に指定します。`icon` には `js/icons.js` のアイコン名を指定します（システム別のテンプレートはアイコンなし）。
