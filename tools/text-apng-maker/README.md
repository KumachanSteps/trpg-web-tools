# 文字画像APNGメーカー

TRPG用の文字アニメーション素材（背景透過APNG）をブラウザだけで作成するツールです。

- **メッセージ**：「戦闘開始」など画面中央のカットイン（テンプレートは「戦闘」「探索・事件」「GM」「シーン・時間」「判定」に分類。「判定」はCoC6・CoC7・エモクロア・ダブクロのシステム別。CoC6・CoC7には「正気度ロール」「SANチェック」もあり、ホラー風のノイズで表示）
- **トレイラー**：長めの文章を文頭から表示（1文字ずつ・1行ずつ・流れるように・全体を同時に・スクロール、空行でページ送り）。「中央に1文字ずつ」は1文字ずつ画面の中央に大きく出し、タメをおいて全文を叩きつけるように出します（テンプレート「タイプライター」）。「中央から左右に広がる」は各行の文字を中央に少しばらけて重ねて出してから、左右に広げて並べます（テンプレート「中央から左右」）。テンプレートごとに見本の文章があり、書き換えた文章もテンプレートごとに保存されます
- **場所・時間**：探索箇所・シーン・時刻のテロップ（上下から合流・浮かび上がる・字間が縮まる・中央から左右に広がる など）

登場のあとに退場させるかどうかは、プレビュー下の「退場あり」スイッチで切り替えます（オフにすると、文字を表示したまま終わる素材になります）。その左の「登場あり」をオフにすると、登場の動き（装飾・背景の現れも含む）をなくし、各ページを最初から全部表示した状態で始めます（スクロールのトレイラーは対象外）。

書き出しのループは、テンプレートを選ぶとそのテンプレートに合わせて設定されます（ふだんは「1回再生」、画面に出したままにすることが多いGMと判定のテンプレートは「ずっとループ」）。選んだ後に変えたループは、次にテンプレートを選ぶまで保存されます。「ずっとループ」のときは、自動入力のファイル名の末尾に「_ループ」がつきます（手入力したファイル名はそのまま）。

表示中の動きには「点滅」「時々ノイズ」なども選べます。ノイズ（グリッチ）で左右にずれる2色は、装飾タブの「ノイズの色」で変えられます。線の装飾（下線・ライン・タイトル枠など）には、文字と同じ縁取りをつけることもできます。

フォントは Google Fonts のほか（ハングル用のフォントは「韓国語（ハングル）」、簡体字用のフォントは「中国語（簡体字）」の分類。日本語・欧文のフォントにはハングルが無いため、`fonts.js` の `koFallback` で分類・フォントごとに近い雰囲気のハングルフォントを代替に使います。中国語の文章（日本語フォントに無い簡体字を含み、かなを含まない文章。`isChineseText`）は、`zhFallback` で選んだ近い雰囲気の中国語フォントを日本語フォントより先に使い、日本語フォントにある漢字と無い簡体字とで字形が混ざらないようにしています）、手持ちのフォントファイル（TTF / OTF / WOFF）を「マイフォント」に登録して使えます（ファイルはこのブラウザの IndexedDB にだけ保存）。文字の色・斜体（イタリック）はフォントタブでも変更できます。

書き出し形式は APNG / WebP / PNG静止画 / 連番PNG（ZIP）。APNG（オレンジ）と WebP（灰青）は同じ大きさのボタンで並べ、その下に違いを一文で案内しています。APNG は劣化がなく、256色に減色すると最も軽くなります。WebP はフルカラーの非可逆圧縮（画質 90%、`main.js` の `WEBP_QUALITY`）で、文字のアニメーションではフルカラーの APNG の半分前後、256色の APNG よりは大きめになります。WebP の書き出しはブラウザの WebP 書き出し（`canvas.toBlob`）を使うため、Safari では使えません（案内を出します）。画面表示は日本語・英語・韓国語・中国語（簡体字）に対応しています（ヘッダーの JP | EN | KR | CN で切り替え）。韓国語・中国語の表示ではテンプレートの見本の文章もその言語になります（書き換えていない見本は、言語を切り替えると新しい言語の見本に置き換わります）。初めて開いたときは、ブラウザの言語設定（優先する言語の順）から対応している言語を選びます（どれにも対応していなければ英語）。ヘッダーで言語を選ぶとこのブラウザに保存され、次からはブラウザの言語よりも優先します。

生成した画像の利用ルールは、ヘッダーの「利用ルール」（かんたん版）と `terms.html`（かんたん版＋利用規約の詳細版）で案内しています。書き出し結果とフッターからも開け、クレジット表記はワンクリックでコピーできます。英語・韓国語・中国語の表示では、かんたん版の参考訳を表示します（日本語版が正式）。

## ファイル構成

```text
tools/text-apng-maker/
├─ index.html
├─ terms.html          利用ルール（かんたん版）と利用規約（詳細版）。かんたん版は js/i18n.js の rules と同じ文言なので、直すときは両方を合わせる
├─ css/text-apng-maker.css
└─ js/
   ├─ engine.js        レイアウト（横書き・縦書き・禁則・自動縮小）、タイムライン、エフェクト、描画
   ├─ apng-encoder.js  APNG / ZIP エンコーダー（外部ライブラリなし）
   ├─ webp-encoder.js  アニメーションWebP の組み立て（1枚ずつブラウザで WebP にして、変化した矩形だけを ANMF に入れる）
   ├─ fonts.js         Google Fonts の遅延読み込み、フォントファイルの登録（IndexedDB に保存）・PCフォントの利用
   ├─ presets.js       モード別の初期値・テンプレート・スタイル/グラデーション/サイズのプリセット
   ├─ controls.js      設定パネル（宣言的なスキーマからUIを生成）と効果カードのミニプレビュー
   ├─ icons.js         テンプレートのアイコン（線画のSVG）
   ├─ i18n.js          画面文言（日本語 / 한국어 / English / 中文）
   ├─ main.js          状態管理・保存、プレビュー再生、書き出し処理
   └─ shortcut.js      キーボードショートカット
```

## 仕組みのメモ

- 描画は決定的（乱数は時刻と文字番号から生成）なので、プレビューと書き出しの見た目が一致します。
- 文字ごとに「光彩」「影＋外側の縁取り」「縁取り＋塗り」の3層のスプライトを事前に作り、フェード中に下の層が透けないよう本体の形でくり抜いています。
- ぼかしは文字スプライト単位の小さなキャンバスでかけています（全面レイヤーに `ctx.filter` をかけるより大幅に高速）。
- 「中央に1文字ずつ」の大きな文字は、画像の短い辺に合わせた大きさで文字ごとに別のスプライトを作ります（拡大してぼやけないように）。使った順に残し、合計の画素数が上限を超えたら古いものから捨てます。
- APNGはブラウザ標準の `CompressionStream('deflate')` で圧縮し、前フレームとの差分矩形だけを保存します（dispose: NONE / blend: SOURCE）。同じ絵が続くフレームは1枚にまとめて表示時間を延ばします。
- 256色モードは1回目の走査で変化した領域の色だけを集計し（メディアンカット＋k-means）、2回目の走査で変化した矩形だけをパレット番号に変換します。255色以内に収まる場合は劣化なしのパレットになります。
- 「APNG非対応の環境では完成状態の静止画を表示」をオンにすると、アニメーションとは別のデフォルト画像（IDAT）として完成状態を埋め込みます。

## 動作要件

- `CompressionStream` に対応したブラウザ（Chrome / Edge 80+、Firefox 113+、Safari 16.4+）。
- Google Fonts を使うにはネットワーク接続が必要です（読み込めない場合は代替フォントで描画します）。
- 画面の幅は 320px 以上を想定しています。1080px 以下は1列（プレビューが上）、760px 以下はスマートフォン向けの表示、420px 以下はカテゴリ名をアイコンの下に置きます。書き出しの設定欄は、選択肢の文字が欠けない幅より狭くせず、入りきらない欄を次の行へ回します。ヘッダーはタイトルを1行に保ち、ボタンの側を折り返します。
- スマートフォン向けの表示（760px 以下、`main.js` の「スマートフォン表示」）：
  - ヘッダーは画面上部に固定します。ページの先頭では2行（タイトル・共有・テーマ／観測所・言語・使い方・利用ルール）です。スクロールしたときと設定を開いたときは1行（タイトル・言語・テーマ・⋯）に縮め、観測所・使い方・利用ルール・共有は ⋯ の中に入れます。
  - 設定パネルは画面下からせり上がるシート（`body[data-sheet]` が `peek` / `half` / `full`）にしています。バーを上下にスワイプするか「設定」を押して開閉します。
    - 閉じているときもバーに、いまのモードとテンプレートが出ます。
    - 半分まで開いたときは、プレビューと再生ボタンが見える高さで止めます。
    - シートの中身を一番上までスクロールしてから下に引くと閉じます。
    - 文字の入力中はキーボードの上までシートを広げます。
  - プレビューはシートの後ろに置いたままにします。書き出し（形式・FPS・ループ・ファイル名）はプレビューの下にあり、ページをスクロールするか、バーの「書き出し ↓」で移動します。
  - ヘッダーとページの余白の指定は `.maker-header` / `.maker-shell` の中だけに効かせています（同じCSSを読む `terms.html` は元の表示のまま）。
  - 入力欄の文字は16pxにしています（iOS は16px未満の入力欄にフォーカスすると画面を拡大するため）。キーボードの高さは、入力欄にフォーカスがあり、ピンチで拡大していないときだけ数えます。

## テンプレートの追加

`js/presets.js` の `TEMPLATES` に、モードごとの配列として追加します。`patch` には初期値（`BASE`）からの差分だけを書きます。文章は `text` / `subText` に日本語・英語・韓国語・中国語（簡体字）を `T(ja, en, ko, zh)` で用意します（設定パネル・テンプレート名の文言も同じ。画面の文言は `js/i18n.js`）。メッセージのテンプレートには、分類（`TEMPLATE_GROUPS` のID）を `group` に指定します。分類に `systems` がある場合は、システムのIDを `system` に指定します。`icon` には `js/icons.js` のアイコン名を指定します（システム別のテンプレートはアイコンなし）。テンプレートの書き出しのループの初期値は分類で決まり（`LOOP_BY_GROUP`：GM・判定は「ずっとループ」、ほかは「1回再生」）、テンプレートに `loop`（`'once'` / `'infinite'`）を書くとそちらが優先されます。
