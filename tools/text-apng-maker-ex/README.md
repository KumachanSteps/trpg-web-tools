# 文字画像APNGメーカーEX

TRPG用の文字アニメーション素材（背景透過APNG）をブラウザだけで作成するツールです。

- **メッセージ**：「戦闘開始」など画面中央のカットイン（テンプレートは「戦闘」「探索・事件」「GM」「シーン・時間」「判定」に分類。「判定」はCoC6・CoC7・エモクロア・ダブクロのシステム別）
- **トレイラー**：長めの文章を文頭から表示（1文字ずつ・1行ずつ・流れるように・全体を同時に・スクロール、空行でページ送り）。「中央に1文字ずつ」は1文字ずつ画面の中央に大きく出し、タメをおいて全文を叩きつけるように出します（テンプレート「タイプライター」）。「中央から左右に広がる」は各行の文字を中央に少しばらけて重ねて出してから、左右に広げて並べます（テンプレート「中央から左右」）。テンプレートごとに見本の文章があり、書き換えた文章もテンプレートごとに保存されます
- **場所・時間**：探索箇所・シーン・時刻のテロップ（上下から合流・浮かび上がる・字間が縮まる・中央から左右に広がる など）

登場のあとに退場させるかどうかは、プレビュー下の「退場あり」スイッチで切り替えます（オフにすると、文字を表示したまま終わる素材になります）。

書き出しのループは、テンプレートを選ぶとそのテンプレートに合わせて設定されます（ふだんは「1回再生」、画面に出したままにすることが多いGMと判定のテンプレートは「ずっとループ」）。選んだ後に変えたループは、次にテンプレートを選ぶまで保存されます。「ずっとループ」のときは、自動入力のファイル名の末尾に「_ループ」がつきます（手入力したファイル名はそのまま）。

表示中の動きには「点滅」「時々ノイズ」なども選べます。ノイズ（グリッチ）で左右にずれる2色は、装飾タブの「ノイズの色」で変えられます。線の装飾（下線・ライン・タイトル枠など）には、文字と同じ縁取りをつけることもできます。

フォントは Google Fonts のほか（ハングル用のフォントは「韓国語（ハングル）」の分類。日本語・欧文のフォントにはハングルが無いため、`fonts.js` の `koFallback` で分類・フォントごとに近い雰囲気のハングルフォントを代替に使います）、手持ちのフォントファイル（TTF / OTF / WOFF）を「マイフォント」に登録して使えます（ファイルはこのブラウザの IndexedDB にだけ保存）。文字の色・斜体（イタリック）はフォントタブでも変更できます。

書き出し形式は APNG / PNG静止画 / 連番PNG（ZIP）。画面表示は日本語・韓国語・英語に対応しています（ヘッダーの JP | KR | EN で切り替え）。韓国語表示ではテンプレートの見本の文章も韓国語になります。

生成した画像の利用ルールは、ヘッダーの「利用ルール」（かんたん版）と `terms.html`（かんたん版＋利用規約の詳細版）で案内しています。書き出し結果とフッターからも開け、クレジット表記はワンクリックでコピーできます。英語・韓国語表示では、かんたん版の参考訳を表示します（日本語版が正式）。

## ファイル構成

```text
tools/text-apng-maker-ex/
├─ index.html
├─ terms.html          利用ルール（かんたん版）と利用規約（詳細版）。かんたん版は js/i18n.js の rules と同じ文言なので、直すときは両方を合わせる
├─ css/text-apng-maker-ex.css
└─ js/
   ├─ engine.js        レイアウト（横書き・縦書き・禁則・自動縮小）、タイムライン、エフェクト、描画
   ├─ fx-fire.js       炎の演出（炎の壁・走る炎・火炎ブレス・燃える文字・燃える文字の演出）。演出の色の色相で炎の色を回す
   ├─ fx-ash.js        環境の演出：風に舞う灰（灰色・黒）。書き出しの長さで継ぎ目なくループ
   ├─ apng-encoder.js  APNG / ZIP エンコーダー（外部ライブラリなし）
   ├─ fonts.js         Google Fonts の遅延読み込み、フォントファイルの登録（IndexedDB に保存）・PCフォントの利用
   ├─ presets.js       モード別の初期値・テンプレート・スタイル/グラデーション/サイズのプリセット
   ├─ controls.js      設定パネル（宣言的なスキーマからUIを生成）と効果カードのミニプレビュー
   ├─ icons.js         テンプレートのアイコン（線画のSVG）
   ├─ i18n.js          画面文言（日本語 / 한국어 / English）
   ├─ main.js          状態管理・保存、プレビュー再生、書き出し処理
   └─ shortcut.js      キーボードショートカット
```

## 仕組みのメモ

- 描画は決定的（乱数は時刻と文字番号から生成）なので、プレビューと書き出しの見た目が一致します。
- 文字ごとに「光彩」「影＋外側の縁取り」「縁取り＋塗り」の3層のスプライトを事前に作り、フェード中に下の層が透けないよう本体の形でくり抜いています。
- ぼかしは文字スプライト単位の小さなキャンバスでかけています（全面レイヤーに `ctx.filter` をかけるより大幅に高速）。
- 「中央に1文字ずつ」の大きな文字は、画像の短い辺に合わせた大きさで文字ごとに別のスプライトを作ります（拡大してぼやけないように）。使った順に残し、合計の画素数が上限を超えたら古いものから捨てます。
- APNGはブラウザ標準の `CompressionStream('deflate')` で圧縮し、前フレームとの差分矩形だけを保存します（dispose: NONE / blend: SOURCE）。同じ絵が続くフレームは1枚にまとめて表示時間を延ばします。
- 256色モードは1回目の走査で変化した領域の色だけを集計し（メディアンカット＋k-means）、2回目の走査で変化した矩形だけをパレット番号に変換します。パレット番号の画像は、フィルターなしとアダプティブフィルターの両方で圧縮して小さいほうを使います。255色以内に収まる場合は劣化なしのパレットになります。
- 「APNG非対応の環境では完成状態の静止画を表示」をオンにすると、アニメーションとは別のデフォルト画像（IDAT）として完成状態を埋め込みます。

## 動作要件

- `CompressionStream` に対応したブラウザ（Chrome / Edge 80+、Firefox 113+、Safari 16.4+）。
- Google Fonts を使うにはネットワーク接続が必要です（読み込めない場合は代替フォントで描画します）。
- 画面の幅は 320px 以上を想定しています。1080px 以下は1列（プレビューが上）、760px 以下はスマートフォン向けの詰めた表示、420px 以下はカテゴリ名をアイコンの下に置きます。書き出しの設定欄は、選択肢の文字が欠けない幅より狭くせず、入りきらない欄を次の行へ回します。ヘッダーはタイトルを1行に保ち、ボタンの側を折り返します。

## テンプレートの追加

`js/presets.js` の `TEMPLATES` に、モードごとの配列として追加します。`patch` には初期値（`BASE`）からの差分だけを書きます。文章は `text` / `subText` に日本語・英語・韓国語を `T(ja, en, ko)` で用意します（設定パネル・テンプレート名の文言も同じ）。メッセージのテンプレートには、分類（`TEMPLATE_GROUPS` のID）を `group` に指定します。分類に `systems` がある場合は、システムのIDを `system` に指定します。`icon` には `js/icons.js` のアイコン名を指定します（システム別のテンプレートはアイコンなし）。テンプレートの書き出しのループの初期値は分類で決まり（`LOOP_BY_GROUP`：GM・判定は「ずっとループ」、ほかは「1回再生」）、テンプレートに `loop`（`'once'` / `'infinite'`）を書くとそちらが優先されます。テンプレートに `size`（`{ width, height, sizePreset }`）や `fps` を書くと、選んだときに画像サイズ・フレームレートもその値になります（炎のテンプレートは試作と同じ 960×540、書き出しの目安 5MB に収めるため）。
