✦ A 卓報告ジェネレータ

v1.73 2026.10.07

SNSの卓報告パターンをもとに、複数スタイルのX向け報告文を生成できます。 シナリオ名、参加者、END、装飾スタイルを入力して、コピーしやすい卓報告文を作成します。

使い方

  1. ① 入力：テンプレートを選び、システム、シナリオ名、KP / GM / DL、PC / PL、ENDなどを入力します。
  2. ② 仕上げ：プレビューで文字スタイルや装飾を選び、本文を直接編集します。
  3. ③ 投稿：「コピー」または「𝕏 に投稿」から投稿画面を開きます。
  4. スマートフォンでは下部のバーで「① 入力」「② 仕上げ」を切り替えます。入力中も上部のライブプレビューで仕上がりを確認できます。

ショートカット

Cmd / Ctrl + Shift + C
プレビュー本文をコピーします（Cmd / Ctrl + Enter も可）。
Cmd / Ctrl + Shift + P
プレビュー本文を 𝕏 に投稿します。
Cmd / Ctrl + Z
プレビューの編集を1つ元に戻します。
Cmd / Ctrl + Shift + Z
元に戻した編集をやり直します。
Cmd / Ctrl + E
プレビュー編集欄へフォーカスします。
Cmd + Option + ↑ / ↓
卓報告サンプルリストを前後に切り替えます。
Cmd + Option + ← / →
文字スタイル（フォント）を前後に切り替えます。
Cmd + Option + R
手動編集を破棄し、入力内容からプレビューを作り直します。
?
このショートカットパネルを開閉します。
Esc
使い方 / ショートカットのパネルを閉じます。

Windows では Cmd を Ctrl、Option を Alt に読み替えてください。

入力

0 / 280

SNS実例の構造だけを参考にしたテンプレートです。

システム名・役職・枠名・END・日付など、テンプレート側で指定された部分だけ変換します。

敬称

緑の＋で進行役を追加できます。KPC/KP型では、名前欄に「KPC名 / KP名」のように入れると綺麗です。

HO、PC名、PL名を1行で入力します。HO補足は通常未入力でOKです。

枠が PC/PL・PL/PC の場合は見出しに反映します。PC1・HO1 は個別行に表示されます。

クリックすると、右側プレビューの編集中カーソル位置に挿入されます。

X風プレビュー / 編集

Session Report @taku_houkoku
0 / 280 手動編集あり OK

文字数は簡易カウントです。URL短縮や絵文字幅など、X本体の厳密な仕様とは異なる場合があります。
