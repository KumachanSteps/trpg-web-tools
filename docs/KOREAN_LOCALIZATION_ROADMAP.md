# 韓国語ローカライズ計画

更新日: 2026-10-01

## 対象と完了条件

対象は `assets/data/tools.json` で `status: "available"` のページです。

各ページは、次を満たした時点で韓国語対応完了とします。

- ヘッダーに `JP | EN | KR` の明示的な言語スイッチャーがある
- `KR` 選択時に `<html lang="ko">` になる
- 選択言語が `localStorage` に保存され、再訪時に復元される
- タイトル、説明、入力ラベル、ボタン、補足、エラー、完了通知が韓国語になる
- ユーザー入力、生成結果、保存済みデータは言語切替で失われない
- PCとモバイルで表示崩れがなく、キーボードでも言語を切り替えられる
- 日本語・英語の既存機能に回帰がない

## 実装順

1. 共通入口の観測所で3言語の保存・切替・フォールバック方式を確立する。
2. 優先度1から順に、ページ固有の辞書とスイッチャーを3言語化する。
3. 各ページごとに完了条件を確認してから次へ進む。
4. すべての使用可能ページ完了後、`production`、`idea` の各ページを別フェーズで棚卸しする。

## 翻訳キーの方針

- 内部言語コードは日本語 `ja`、英語 `en`、韓国語 `ko` を使う。
- 表示ラベルは `JP`、`EN`、`KR` とする。
- 欠落キーは日本語へフォールバックし、画面や操作を壊さない。
- 固有名詞、TRPG用語、外部サービス名は各ページで表記を統一する。
