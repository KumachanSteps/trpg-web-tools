# 韓国語ローカライズ計画

更新日: 2026-10-01

## 完了条件

- ヘッダーに `JP | EN | KR` の言語スイッチャーがある
- `KR` 選択時に `<html lang="ko">` になる
- 選択言語を保存し、再訪時に復元する
- タイトル、説明、入力ラベル、ボタン、補足、エラー、通知が韓国語になる
- 言語切替で入力中・保存済みデータを失わない
- PC・モバイル・キーボード操作を確認する
- 日本語・英語の既存機能に回帰がない
