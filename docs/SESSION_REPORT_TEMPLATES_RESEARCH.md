## 1. 調査で分かったこと

### 1-1. 並び順はほぼ共通
ほとんどのテンプレ型投稿が、次の順番を守っています。

```
(見出し/ハッシュタグ) → システム → 『シナリオ名』 → (作者) → (敬称略)
→ KP / GM / DL（+ SKP / SGM）→ PC/PL 一覧 → END・結果 → (日付) → 感想1〜3行 → (ハッシュタグ)
```

### 1-2. 方針（2026-10-07 確定）
- テンプレートに **固定のハッシュタグ・見出しラベル（`#卓報告 #TRPG`、`▐█ 卓報告 █▌`、`【通過報告】` など）は入れない**
- **日付・時間帯は入れない**
- **日記・キャンペーン型、マダミス専用型は作らない**
- **囲み装飾をテンプレートに含める**（ツールの売り）。テンプレート名に、使っている囲み記号を入れる
- 「HO / PC / PL」見出し＋「HO1 ┊ PC / PL」の行の型は採用

### 1-3. 実例で使われていた囲み装飾
| 囲み | 実例での使われ方 |
|---|---|
| `⟡.· ⎯⎯⎯⎯ ⟡.·` | **最多**。PC/PL ブロックを上下で挟み、END・感想は外 |
| `────────` | 情報全体を上下で囲む、または感想との区切り |
| `━━━╋━━━━╋━━━` | 上下で挟み、中は `HO / PC / PL` ＋ `HO1 ┊ …` |
| `ෆ・┈・┈・⊹ … ・┈・┈・ෆ` | 上下で挟み、タイトルは `【 】`、中は `｜KP` などのラベル |
| `◣ タイトル ◥` | タイトルだけを括り、`- KP` `- HO1` の箇条書き＋`➤ END` |
| `＿＿＿＿◢ 結果` | 下側の線に結果を乗せる |
| `⧉ システム` ＋ `｜𝗗𝗟` | 枠線なし、ラベル記号で縦に区切る（エモクロアで人気） |

既存テンプレートにある `✦ ┈┈ ✦`、`══════`、`‧₊˚ ୨ ୧ ˚₊` も残す価値あり。  
追加指定（2026-10-07）：`─── ･ ｡☆*☽*☆ﾟ.─────`、`✼••┈┈••✼`、`⟡.·*.····⟡.·*.`（ドット）、`⌜ ⌟`、`▮ ▮` もテンプレートに含める。10種の上限はなし。
