# TRPG WEBツール観測所

TRPGのセッション準備・進行・振り返りを、ブラウザ上で手軽に支援する個人制作のWebツール集です。

**公開サイト:** https://kumachansteps.github.io/trpg-web-tools/

## このサイトの目的

KP／GM・PLが行う繰り返し作業や情報整理の負担を軽くし、TRPGを遊ぶ時間と創作を楽しむ余裕を増やすことを目的としています。

主な対象は次のとおりです。

- セッション前の準備、キャラクター・素材・ルールの整理
- セッション中の情報確認、演出、GM／KP支援
- セッション後のログ解析、成長処理、卓報告、記録
- TRPG配信・シナリオ制作・SNS発信の補助

本サイトは個人が運営する非公式のファンメイドサイトであり、特定のTRPG出版社、シナリオ制作者、外部サービスまたはプラットフォームとの公式な提携・承認関係はありません。
